# MUĞLA BÜTÇE SENİN

Next.js katilimci butce platformu.

Referans site incelemesi, sayfa haritasi, mevcut veri sistemi ve kurulum:
[Referans ve altyapi](docs/REFERANS-VE-ALTYAPI.md).

Yerel gelistirme: `npm.cmd run dev -- -p 3001`

Derleme: `npm.cmd run build`

Baglanti denetimi: `npm.cmd run check:navigation -- http://localhost:3001`
